# Ιερός Ναός Αγίας Ταβιθά — Ηλιούπολη

Στατική landing page (HTML/CSS, χωρίς build). Ανοίξτε το `index.html` ή ανεβάστε τον φάκελο σε οποιοδήποτε static hosting (GitHub Pages, Netlify, Vercel).

Προς συμπλήρωση (σημειωμένα με `ΣΥΜΠΛΗΡΩΣΤΕ` στο `index.html`):
- Πρόγραμμα ακολουθιών (οι ώρες είναι ενδεικτικές)
- Διεύθυνση, τηλέφωνο, email, ωράριο γραφείου
